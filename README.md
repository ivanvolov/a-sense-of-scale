# Чувство масштаба — ролик про космические расстояния

Короткий ролик (1920×1080, 30 fps, ~87 с) из трёх сцен про то, насколько велики
космические расстояния. Рисуется обычным Canvas 2D в браузере, снимается
headless-Chromium покадрово и кодируется в mp4. Ни одной платной подписки, ни
одного облачного сервиса: всё считается локально.

```
npm install
npm run render        # out/space-scale.mp4
npm run dev           # http://127.0.0.1:5178 — превью со скрабом и покадровой перемоткой
```

## Почему так, а не Blender / After Effects

Сюжет ролика — шкала: от поверхности Земли (10⁴ м) до орбиты Проксимы (10¹⁶ м).
Настоящий 3D-движок на таком диапазоне ломается: float32 в вершинном буфере
даёт z-fighting и дрожание задолго до 10¹². Поэтому геометрия здесь не
трёхмерная, а «камера + масштаб в пикселях на метр», и любой зум — это
интерполяция **в логарифмическом пространстве** (`logLerp` в `src/lib/math.js`).
Диапазон становится неважен, точность не теряется, а весь ролик — чистая функция
`renderFrame(ctx, t)`.

Побочный выигрыш: превью в браузере и финальный рендер идут по одному и тому же
коду, так что «в превью было иначе» невозможно.

## Устройство

```
src/
  film.js            список сцен + renderFrame(ctx, t) — единственная точка входа
  index.html         превью-плеер и @font-face; экспортирует window.film для рендера
  lib/data.js        ВСЕ числа ролика (СИ, с указанием источника)
  lib/math.js        easing, логарифмическая интерполяция, форматирование чисел
  lib/draw.js        камера, тела, выноски, размерные линии, подписи
  scenes/            earth-moon · sun-au · light-speed · cards (заставка и финал)
tools/
  serve.js           статика (ES-модули не грузятся с file://)
  capture.js         Chromium → PNG-кадры → пайп в ffmpeg → mp4
```

**Числа живут только в `lib/data.js`.** Сцены берут оттуда и геометрию, и текст
подписи: подпись физически не может разойтись с картинкой, которую описывает.
Если поправить радиус Луны — поедет и шар, и «384 400 км», и «30,2 диаметра».

## Что показывают сцены

| # | Сцена | Ход |
|---|-------|-----|
| 01 | Земля и Луна | Один непрерывный отъезд: поверхность → планета целиком → вся система. Затем семь остальных планет выкладываются в просвет и **не влезают** — Нептун упирается в Луну на 3 724 км. В апогее (405 500 км) влезают с запасом 17 376 км. |
| 02 | Солнце и 1 а. е. | Сначала только размеры, с честной плашкой «расстояние — нет», потому что в одном кадре Солнце и Земля в истинном разносе не помещаются. Потом Земля улетает на орбиту, и оба становятся точками. |
| 03 | Скорость света | Отрезок экрана не меняется — меняется его цена. Сперва это 384 400 км и фотон летит **в реальном времени** 1,28 с. Потом тот же отрезок — 1 а. е., скорость та же, и дождаться прилёта можно только ускорив время в 64 раза. |

Про «все планеты влезают между Землёй и Луной»: популярная версия факта неверна
на среднем расстоянии — суммарный диаметр семи планет 380 016 км против просвета
376 292 км. Ролик показывает именно это, а потом честно доигрывает до апогея.

## Команды рендера

```bash
node tools/capture.js                          # весь ролик
node tools/capture.js --scene earth-moon       # одна сцена
node tools/capture.js --from 12 --to 20        # кусок по секундам
node tools/capture.js --stills                 # контактный лист PNG по всем битам
node tools/capture.js --stills 4.5,26,63       # кадры в указанные секунды
node tools/capture.js --jpeg --crf 24 --preset veryfast --scale 960   # быстрый черновик
```

Кадры не пишутся на диск: PNG уходят прямо в stdin ffmpeg, поэтому весь рендер
стоит ровно столько места, сколько занимает готовый mp4 (~11 МБ). Полный проход
1080p — примерно 4 минуты, около 10 кадров в секунду.

## Превью

`npm run dev` поднимает `http://127.0.0.1:5178`. Пробел — play/pause, стрелки —
покадрово, Shift+стрелки — по секунде. Номер кадра в строке состояния совпадает
с номером в рендере, так что «сломанный кадр 1417» можно открыть напрямую.

## Шрифты

Inter и JetBrains Mono подтягиваются из `@fontsource/*` в `node_modules` и
раздаются сервером по `/vendor/...`. В репозитории бинарников нет; после
`npm install` рендер воспроизводится байт в байт. Оба шрифта под SIL OFL 1.1.

## Если добавлять сцены

1. Новый файл в `src/scenes/`, экспортирующий `id`, `title`, `duration`, `draw(ctx, t)`.
   `t` — локальное время сцены в секундах.
2. Числа — в `lib/data.js`, не в сцене.
3. Добавить сцену в массив в `film.js`. Стыки затемняются автоматически.
4. Никакого `Date.now()` и `Math.random()` без сида: кадр обязан быть функцией
   только от `t`, иначе рендер разъедется с превью.

Идеи следующих сцен: размер атома (ядро как шарик в центре стадиона),
миллион против миллиарда секунд (11,6 суток против 31,7 года), история Земли,
сжатая в одни сутки.

## Источники чисел

NASA/JPL Planetary Fact Sheets (радиусы, расстояния), IAU 2012
(а. е. = 149 597 870 700 м), CODATA (c = 299 792 458 м/с — точно, по определению).
